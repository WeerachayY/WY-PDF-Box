# WY Pdf Box

เว็บแอปจัดการไฟล์ PDF แบบไฟล์เดียว (single-file HTML) ใช้ได้ทั้งคอมพิวเตอร์และมือถือ
ประมวลผลทั้งหมดในเบราว์เซอร์ของผู้ใช้ — **ไฟล์ไม่ถูกอัปโหลดขึ้นเซิร์ฟเวอร์**

## ฟีเจอร์

- แถบ Thumbnail ด้านซ้าย + Page preview ด้านขวา (มือถือพับเก็บแถบได้)
- **จัดการหน้า:** ลบหน้า, สลับลำดับหน้า (ลากบนคอม / ปุ่ม ↑↓ บนมือถือ), หมุนเฉพาะหน้าที่เลือกหรือหมุนทั้งเล่ม
- **รวมไฟล์:** เพิ่มไฟล์ PDF อื่นเข้ามาได้ เลือกวางไว้หน้าแรก แทรกหลังหน้าปัจจุบัน หรือต่อท้าย
- **ขีดเขียน:** ปากกา, ไฮไลต์, กล่องข้อความ (รองรับภาษาไทย), ยางลบ, undo — 5 สี ขนาด S/M/L
- เลือกหลายหน้าพร้อมกันเพื่อหมุน/ลบทีเดียว
- ซูมเข้า/ออก/พอดีจอ
- บันทึกเป็นไฟล์ PDF ใหม่ (`ชื่อเดิม-edited.pdf`) โดยการแก้ไขทั้งหมดถูกฝังลงไฟล์ถาวร

## วิธีใช้

เปิด `index.html` ในเบราว์เซอร์ หรือใช้ผ่าน GitHub Pages ของ repo นี้
(ต้องมีอินเทอร์เน็ตตอนเปิดหน้า เพื่อโหลดไลบรารีจาก CDN)

## ไลบรารีที่ใช้

- [pdf.js](https://mozilla.github.io/pdf.js/) — แสดงผล PDF
- [pdf-lib](https://pdf-lib.js.org/) — แก้ไขและบันทึกไฟล์ PDF

## ข้อจำกัด

- ไฮไลต์เป็นแบบลากแถบสีทับ ไม่ใช่ไฮไลต์ตามตัวอักษร
- แก้ไขข้อความต้นฉบับในไฟล์ไม่ได้
- ไฟล์ที่มีรหัสผ่านอาจเปิดไม่ได้

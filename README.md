# WY Pdf Box

เว็บแอปจัดการไฟล์ PDF แบบไฟล์เดียว (single-file HTML) ใช้ได้ทั้งคอมพิวเตอร์และมือถือ ติดตั้งเป็นแอป (PWA) ได้
ประมวลผลทั้งหมดในเบราว์เซอร์ของผู้ใช้ — **ไฟล์ไม่ถูกอัปโหลดขึ้นเซิร์ฟเวอร์**

## ฟีเจอร์

- แถบ Thumbnail / สารบัญ (Bookmarks) ด้านซ้าย + หน้าเอกสารแบบเลื่อนต่อเนื่องหรือทีละหน้า, หลายไฟล์เป็นแท็บ
- **จัดการหน้า:** ลบ, สลับลำดับ (ลาก / ปุ่ม ↑↓), หมุน, แทรกหน้าเปล่า / จากไฟล์ / จากรูป / จากแท็บอื่น
- **มาร์กอัปที่แก้ไขได้ต่อ:** ปากกา, ไฮไลต์, ข้อความ (ไทย หมุนได้), รูปทรง (เมฆแก้ไข สี่เหลี่ยม วงรี เส้น ลูกศร เส้นหลายจุด),
  ไฮไลต์ / ขีดเส้นใต้ / ขีดฆ่า บนตัวหนังสือในไฟล์, ตราประทับ (อนุมัติ ไม่อนุมัติ ฯลฯ + วันที่และชื่อ), ลายเซ็น, รูปภาพ
  — บันทึกเป็น annotation จริงของ PDF ที่ Acrobat / PDF-XChange / Edge เห็นและแก้ได้ และเปิดกลับมาในแอปนี้ก็ยังแก้ไขได้
- **กรอกฟอร์ม PDF:** ช่องข้อความ (ไทย), ช่องติ๊ก, ตัวเลือกวงกลม, รายการเลือก — Tab ไปช่องถัดไป
- **เปิดไฟล์ที่มีรหัสผ่าน** และไฟล์ที่ล็อกสิทธิ์แก้ไข (บันทึกออกมาแล้วไม่มีรหัสผ่าน)
- **ลิงก์และสารบัญ:** คลิกลิงก์ในหน้าได้ สารบัญและลิงก์ยังอยู่หลังบันทึก / ลบหน้า / แยกไฟล์
- **รวมไฟล์ / แยกไฟล์:** รวมหลายไฟล์เรียงลำดับเองได้, แยกทุก N หน้า / ตามช่วงหน้า / หน้าละไฟล์
- **ส่งออกเป็นรูป** PNG / JPG 96–300 dpi, คัดลอกหน้าเป็นรูป, บีบอัดไฟล์สแกน, พิมพ์
- **บันทึกแบบฝังถาวร (Flatten)** เมื่อต้องการให้มาร์กอัปและค่าฟอร์มกลายเป็นเนื้อหน้า
- ค้นหา / เลือก / คัดลอกตัวหนังสือในไฟล์ (ซ่อมสระไทยจากไฟล์ Word ให้), คีย์ลัดแบบ Acrobat (กด ? ดูทั้งหมด)

## วิธีใช้

เปิด `index.html` ในเบราว์เซอร์ หรือใช้ผ่าน GitHub Pages ของ repo นี้
(ต้องมีอินเทอร์เน็ตตอนเปิดครั้งแรก เพื่อโหลดไลบรารีจาก CDN — หลังติดตั้งเป็นแอปแล้วใช้แบบออฟไลน์ได้)

## ไลบรารีที่ใช้

- [pdf.js](https://mozilla.github.io/pdf.js/) — แสดงผล PDF
- [pdf-lib](https://pdf-lib.js.org/) — แก้ไขและบันทึกไฟล์ PDF

## ข้อจำกัด

- แก้ไขตัวหนังสือต้นฉบับในไฟล์ไม่ได้ (เพิ่มข้อความใหม่ทับได้)
- มาร์กอัปจากแอปนี้ที่ถูกย้ายในโปรแกรมอื่น จะตามตำแหน่งใหม่; แต่ถ้าถูกแก้รูปร่าง/ข้อความในโปรแกรมอื่น
  เมื่อเปิดกลับในแอปนี้จะเห็นเป็นแบบที่บันทึกจากแอปนี้ครั้งล่าสุด
- ข้อความและตราประทับเก็บหน้าตาเป็นรูปความละเอียดสูง (ภาษาไทยจึงแสดงถูกทุกโปรแกรม) ส่วนเนื้อความจริงอยู่ในช่อง Comment
